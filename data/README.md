# Donnees de la these

Ce dossier accueillera les jeux de donnes relatifs a l'etude phytochimique
de *Rugulopteryx okamurae*.

## Organisation prevue

```
data/
├── raw/        # Donnees brutes non traitees (chromatogrammes, spectres RMN)
├── interim/    # Donnees intermediaires de traitement
└── processed/  # Donnees finales analysees (tables, figures source)
```

## Format et depot

Les donnees brutes volumineuses (chromatogrammes HPLC, spectres RMN 1H/13C)
seront deposees sur un entrepot dedie (Nakala / Zenodo) avec un DOI persistant,
conformement au Plan de Gestion des Donnees (voir docs/PGD_Rugulopteryx_okamurae.pdf).
Seules les metadonnees et les tables reduites sont versionnees dans ce depot.

## Origine des echantillons

- Espece : *Rugulopteryx okamurae* (E.Y. Dawson) I.K. Hwang, W.J. Lee & H.S. Kim
- Zone de prelevement : cote mediterraneenne marocaine (detroit de Gibraltar / Alboran)
- Campagnes : a venir (cf. PGD, section 1)
